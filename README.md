## Background

i learned HTML, CSS and JavaScript around 2017, no laptop then, i built Android apps in Java on my phone with Sketchware Pro. [MoonMeet-Android](https://github.com/MoonMeet/MoonMeet-Android) started like that in 2019 and moved to Android Studio a year later, once i could export the project to a PC.

Sketchware wasn't maintained by its developers back then, reverse engineering it was the only solution so i could add .aab support, new signing and more. i worked out that if you load an app's own classes as a jar in Android Studio, a decompiled Java file resolves its imports and compiles. from there you can turn it back into smali and put it in the APK. i shared this with the Sketchware Pro modders, after that i stopped releasing mods publicly.

in 2021 i switched to React Native and rebuilt [Moon Meet](https://github.com/MoonMeet/MoonMeet-CrossPlatform) in bare React Native, it's on the Play Store.

[otp-input](https://github.com/SectionTN/otp-input), an OTP input library for React Native, came out in 2024 before the baccalauréat. after the bac i made [Mentrick](https://play.google.com/store/apps/details?id=org.sectiontn.mindreader), a mind games app first called PlayScope, and [AlgorithmeTN](https://github.com/MoonMeet/AlgorithmeTN), an algorithms app for Tunisian students. most of what i started in 2025 never made it out.

i study at ISET Sidi Bouzid. i'm on macOS now, with Xcode and Swift next to Android Studio.

this year:

- [Encore](https://play.google.com/store/apps/details?id=me.sectiontn.encore): a spaced repetition flashcards app
- [gitposter](https://github.com/SectionTN/gitposter): a printable poster generator for any git repository
- [stale-docs](https://github.com/SectionTN/stale-docs): a hook that flags and patches docs a code edit just made wrong
- [no-trace](https://github.com/SectionTN/no-trace): a Claude Code plugin that keeps AI traces out of commits and PRs
- [react-native-inkpad](https://github.com/SectionTN/react-native-inkpad): a native ink canvas for React Native, androidx.ink on Android and PencilKit on iOS
