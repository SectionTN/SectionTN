## Background

I learned HTML, CSS and JavaScript around 2017. I had no laptop then, so I built Android apps in Java on my phone with Sketchware Pro. [MoonMeet-Android](https://github.com/MoonMeet/MoonMeet-Android) started that way in 2019. It only moved into Android Studio a year later, once I could export the project to a PC.

Reverse engineering came out of the same period. I worked out that if you load an app's own classes as a jar in Android Studio, a decompiled Java file will resolve its imports and compile, which means you can turn it back into smali and put it into the APK. I shared the method with the Sketchware Pro modders, and after that I stopped releasing mods publicly.

React Native took over in 2021. I rebuilt [Moon Meet](https://github.com/MoonMeet/MoonMeet-CrossPlatform) as a cross-platform app on bare React Native and published it on the Play Store. After the baccalauréat in 2024 came [AlgorithmeTN](https://github.com/MoonMeet/AlgorithmeTN), an [OTP input library](https://github.com/SectionTN/otp-input) for React Native, and [Mentrick](https://play.google.com/store/apps/details?id=org.sectiontn.mindreader), which started life as PlayScope. Most of what I started in 2025 never made it out. This year has been [stale-docs](https://github.com/SectionTN/stale-docs), [gitposter](https://github.com/SectionTN/gitposter) and Encore. I study at ISET Sidi Bouzid, and I build interactive French revision platforms for my own courses.
